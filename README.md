# 100Hires Portfolio Project

## Overview

This repository documents the setup process completed as part of the 100Hires application process. The objective was to install the required AI development tools, configure the environment, create a GitHub repository, and document the process.

## Tools Installed

* Cursor IDE
* Claude Code Extension
* OpenAI Codex Extension
* Git for Windows
* GitHub

## Steps Completed

1. Installed Cursor IDE.
2. Installed and configured the Claude Code extension.
3. Logged into Claude.ai and verified access.
4. Installed the OpenAI Codex extension.
5. Created a public GitHub repository.
6. Opened the repository in Cursor.
7. Created and updated the README.md file.
8. Installed and configured Git.
9. Prepared the repository for version control and GitHub submission.

## Challenges Encountered

### Git Installation and Verification

Initially, Git commands were not available in the terminal.

**Resolution:** Installed Git for Windows and verified the installation using Git Bash.

### Extension Authentication

The Claude Code and Codex extensions required authentication through external accounts.

**Resolution:** Successfully completed browser-based authentication and verified access within Cursor.

### Repository Setup

I needed to understand how to connect a local project folder with a GitHub repository.

**Resolution:** Created a public GitHub repository, configured the local project folder, and prepared it for committing and pushing changes.

## Key Learnings

* Installing and configuring AI-assisted development tools.
* Using Git for version control.
* Creating and managing GitHub repositories.
* Documenting technical work using Markdown.

## Outcome

Successfully completed the required setup process and documented all steps, challenges, and learnings in this repository.
